Part A

Prototype Features — Already Built

12 features  ✓
A1
Complementary Filter (100 Hz)
Firmware • Sensor Fusion
Fuses MPU6050 accelerometer + gyroscope at 100 Hz using angle = 0.96 × (angle + gyro × dt) + 0.04 × accel. Eliminates drift and vibration noise for smooth, accurate knee angle in all conditions.
A2
Smart Gait State Machine
Firmware • Control Logic
Auto-detects activity and adjusts servo assist: IDLE (standing, no assist) → WALKING (assist flexion) → SITTING (seated position) → IDLE. Prevents over-assisting at each stage.
A3
Stand-Up Boost
Firmware • Assistive Logic
Detects rising from seated position. Auto-injects +10° torque boost and doubles servo speed to assist at the hardest moment — the initial push-off from a chair.
A4
Battery Monitoring + Safety Cutoff
Hardware • Safety
Reads 2S LiPo voltage via GPIO 34 voltage divider. Three-tier protection: Normal operation → Low Battery alert at 6.5V (LED + buzzer) → Motor hard-kill at 3.0V to prevent fire or battery damage.
A5
Physical Mode Button
Hardware • UX
Smart press detection on GPIO 4. Short press (<2s) is ignored to prevent accidental mode changes. Long press (≥2s) toggles AUTO/MANUAL. LED indicator: Green = AUTO, Blue = MANUAL.
A6
OLED Live Display (128×64)
Hardware • Feedback
SSD1306 OLED shows real-time data without a phone: knee angle, mode, battery %, gait state, and confidence bar. Device fully operational standalone without BLE connection.
A7
BLE Nordic UART Service (NUS)
Firmware • Connectivity
Streams live telemetry at ~5Hz: ANGLE, BAT, VOLT, MODE, PITCH, FSR, CONF, CAL fields. Bidirectionally receives all PWA commands over Nordic UART profile. Auto-reconnects on disconnect.
A8
WebAuthn Biometric Lock
PWA • Security
PWA locks on load. Unlock via PIN or fingerprint/face scan using the WebAuthn standard (W3C Level 2) — the same technology used by banks. Credentials stored locally, never transmitted.
A9
Emergency SOS + GPS + WhatsApp
PWA • Safety
One tap: fetches GPS coordinates via Geolocation API → builds Google Maps link → dispatches WhatsApp message to saved emergency contact. Gracefully falls back to message without location if GPS unavailable.
A10
Voice Control — 4 Languages
PWA • Accessibility
Continuous hands-free control via Web Speech API. Recognizes in English, Hindi, Kannada, and Telugu. Works fully offline. Commands: assist, relax, walk, sit, stand, auto, manual, pain, fine, hard.
A11
Live Telemetry Chart
PWA • Monitoring
Real-time scrolling pitch angle graph (last 30 seconds) rendered via Chart.js. Auto-updates with BLE data. Visually reveals walking patterns, sitting events, and assist triggers at a glance.
A12
Session Timer + Activity Log Export
PWA • Data
Session timer starts on BLE connect (HH:MM:SS). Every command timestamped in Activity Log. Export button downloads full session log as .txt for medical records, physiotherapy tracking, and research analysis.
Part B

Novel Features — Patent-Eligible Innovations

6 novel features  ⭐
N1
Self-Calibrating Thresholds
Novel • Firmware
⭐⭐⭐⭐
Derives personal gait thresholds from a 12-second guided body-motion onboarding: Stand 3s → Sit 3s → March 6s. Computes walk and sit thresholds directly from the user's own measured range of motion.
Novel vs. Prior Art: Existing adaptive systems use ML/neural networks trained on population datasets (≥50 subjects) requiring powerful processors and pre-collected data. This method derives thresholds entirely from the individual's real-time body motion on a low-cost microcontroller.
N2
FSR + IMU Dual-Sensor Gait Fusion
Novel • Sensing
⭐⭐⭐
Requires joint confirmation from both IMU angle and FSR foot pressure before triggering assistance. Eliminates false positives during squatting, kneeling, or stationary bent-knee postures.
Novel vs. Prior Art: Sub-₹15,000 exoskeletons use IMU-only control. FSR+IMU fusion systems exist but cost ₹5 lakh+. This system achieves clinical-grade dual-sensor confirmation at ₹10,000 total cost.
N3
Live Sensor Confidence Signal (0–100%)
Novel • Firmware • Transparency
⭐⭐⭐⭐⭐
Computes and displays a real-time confidence score representing agreement between IMU and FSR sensors. IMU confidence = margin from decision boundary; FSR confidence = unambiguity of pressure reading. Combined score displayed on OLED as a graphical bar and transmitted over BLE telemetry.
Confidence RangeInterpretationOLED Indicator
80 – 100%Both sensors clearly agree — trust the readingFull Green bar
40 – 79%One sensor borderline — treat with cautionPartial Yellow bar
0 – 39%Sensors contradict — do not rely on readingShort Red bar
Novel vs. Prior Art: No knee exoskeleton product or research prototype has been found to expose a quantified, real-time sensor confidence metric to the end user. This represents the first transparent uncertainty indicator in wearable lower-limb robotics and is independently publishable.
N4
NVS Persistent Personal Calibration
Novel • Firmware • Storage
⭐⭐⭐⭐
Personal thresholds persisted to ESP32 internal flash via NVS (Non-Volatile Storage) API. Survive power-off, battery removal, and firmware resets. A calDone flag prevents factory defaults from overwriting personalized values.
Novel vs. Prior Art: All commercial and research exoskeletons revert to factory parameters on power-off. This system permanently stores per-user calibration — eliminating re-calibration before every session.
N5
Zero-Install Browser PWA Controller
Novel • PWA • Web Bluetooth
⭐⭐⭐⭐
Full-featured exoskeleton controller delivered as a Progressive Web App over Web Bluetooth API, operable in any Chromium browser with zero installation, no app store, and no account creation. Deployable via local network or static web host.
Novel vs. Prior Art: ReWalk, Indego, Keeogo, and all surveyed commercial exoskeleton systems require proprietary native iOS or Android applications. No deployed exoskeleton system utilises Web Bluetooth as its primary control interface.
N6
Subjective Self-Report Fusion
Novel • Research • Data Fusion
⭐⭐⭐⭐⭐
User annotates subjective experience (PAIN / FINE / HARD) via on-screen button or spoken voice command during an active session. The system immediately records the annotation alongside a complete sensor snapshot at the identical timestamp, creating fused objective-subjective data records for clinical and research analysis.
